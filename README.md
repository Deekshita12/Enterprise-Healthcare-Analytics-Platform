# 📌 Project Overview

The **Enterprise Healthcare Analytics Platform** is an end-to-end analytics solution designed to transform hospital operational data into actionable business intelligence.

The platform integrates **Python**, **MySQL**, **SQL** and **Power BI** to support executive decision-making across patient flow, workforce management, finance, laboratory operations, pharmacy operations, bed utilization and hospital performance.

# 🏥 About the Project

This project simulates an enterprise hospital analytics environment by building a production-style data pipeline from raw datasets through database design, data engineering, SQL analytics and executive dashboards.

Key focus areas include:

- Patient Flow
- Admissions
- Bed Management
- Workforce Analytics
- Laboratory Analytics
- Pharmacy Analytics
- Financial Analytics
- Executive Command Center

---

# 🎯 Business Problem

Hospitals generate large volumes of operational data spread across multiple departments. Without centralized analytics, executives struggle to monitor KPIs, optimize resources, reduce patient wait times and improve operational efficiency.

This platform addresses these challenges by integrating operational data into a single analytics ecosystem.
